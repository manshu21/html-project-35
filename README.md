# Workout Budyyy 

Workout Budyyy is a MERN stack workout tracking application.

## Features

- Add a new workout
- View all workouts
- Delete workouts
- Workout creation time
- Responsive design
- React Context API
- useReducer for state management
- Express REST API
- MongoDB Atlas database
- Mongoose validation
- Frontend and backend error handling

## Technologies Used

### Frontend
- React
- Vite
- Context API
- useReducer
- CSS
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
